# MPU6050 IMU 接线登记

> 记录 B-Box 项目中 MPU6050（6 轴加速度计 + 陀螺仪）与 ESP32-S3（A/B 板同型号）的接线方式。
> 固件侧集成见 `src/main_wired.cpp`（有线协议固件，已支持自动检测 IMU，未接则优雅降级为纯模拟）。

---

## 1. 引脚接线表

| MPU6050 引脚 | 接 ESP32-S3 | 作用 |
|---|---|---|
| `VCC` | `3V3` | 3.3V 供电（**勿接 5V**，模块多数板载 LDO 但直供 3V3 最稳） |
| `GND` | `GND` | 公共地 |
| `SCL` | `GPIO9` | I²C 时钟（SCL） |
| `SDA` | `GPIO8` | I²C 数据（SDA） |
| `XDA` | 不接 | 外接辅助 I²C 设备的数据线（主机模式用，本项目不用） |
| `XCL` | 不接 | 外接辅助 I²C 设备的时钟线（主机模式用，本项目不用） |
| `AD0` | `GND` | 地址选择：接 GND → I²C 地址固定 `0x68`（接 VCC 则为 `0x69`） |
| `INT` | `GPIO10` | 数据就绪 / 运动检测中断输出 |

## 2. 接线示意

```
   ESP32-S3                         MPU6050
  ┌──────────┐                    ┌──────────┐
  │      3V3 ●───────────────────●│ VCC      │
  │      GND ●──────────┬────────●│ GND      │
  │    GPIO9 ●──────────┼────────●│ SCL      │
  │    GPIO8 ●──────────┼────────●│ SDA      │
  │   GPIO10 ●──────────┼────────●│ INT      │
  │          │          └────────●│ AD0  →地 │  (AD0 接 GND ⇒ 地址 0x68)
  └──────────┘                    │ XDA  ✕   │  (悬空)
                                  │ XCL  ✕   │  (悬空)
                                  └──────────┘
```

## 3. 关键参数（与固件保持一致）

| 项目 | 值 | 说明 |
|---|---|---|
| 总线 | I²C | `Wire`，默认 400kHz |
| SDA / SCL | `GPIO8` / `GPIO9` | 固件 `Wire.begin(8, 9)` |
| I²C 地址 | `0x68` | AD0 接 GND；`WHO_AM_I(0x75)` 应读回 `0x68` |
| INT 引脚 | `GPIO10` | 配置为输入，数据就绪中断（当前固件以轮询为主，INT 备用） |
| 加速度量程 | ±2g | `ACCEL_CONFIG=0x00`，灵敏度 16384 LSB/g |
| 陀螺量程 | ±250°/s | `GYRO_CONFIG=0x00`，灵敏度 131 LSB/(°/s) |
| DLPF | ~44Hz | `CONFIG=0x03`，抑制高频抖动 |

## 4. 接线自检

1. 上电后打开串口监视器（`pio device monitor -e wired_sim` 或 `python docs\monitor.py`）。
2. 看 `BOOT` 之后的日志：
   - 已正确接线：`LOG,IMU ok whoami=0x68`，随后每秒一条 `IMU,<ax>,<ay>,<az>,<gx>,<gy>,<gz>,<ms>`。
   - 未接 / 接错：`LOG,IMU not found (whoami=0xNN)`，固件退回纯模拟模式，其余协议功能不受影响。
3. 静止平放时 `az` 应约为 `1.00`（g），三轴陀螺应接近 `0`；轻晃模块数值随之变化即接线正常。
4. 发送 `CALIBRATE` 命令可对陀螺零偏做一次静态标定（详见 `docs/PROTOCOL.md` §4）。

> 单位约定：加速度以 **g** 为单位（1g≈9.8m/s²），陀螺以 **°/s** 为单位。

## 5. 组装方向约定（强制）

固件（≥0.8.0-tiltpush）的前后左右判向锚定在**传感器自身轴**上（倾斜补偿去 yaw），
因此安装方向必须固定，装配与后期调试才能对上"正方向"。

### 硬件约定

| 项目 | 约定 |
|---|---|
| 正方向定义 | MPU6050 芯片丝印坐标 **+Y 轴 = 盒体"前"** |
| 安装姿态 | 模块 PCB 水平安装，元件面朝上（+Z 朝天） |
| 外壳标记 | 外壳顶面印/贴 **箭头指向"前"**，与模块 +Y 对齐 |
| 防错 | 模块安装孔位/卡槽做成非对称，物理上装不反 |

MPU6050 模块轴向以丝印面朝上看：模块丝印通常印有 X/Y 轴向箭头，以丝印为准对齐外壳箭头。

### 软件校准（装配后验证）

1. 上电静置，等 `BOOT` 后绿灯就绪。
2. 沿外壳箭头方向平推一下，应上报 `EVT,...,MOVE_FORWARD`。
3. 若方向不对，用 `ORIENT,<swapXY>,<signX>,<signY>` 运行时修正映射，例如：
   - 前后颠倒：`ORIENT,0,1,-1`
   - 前后↔左右互换：`ORIENT,1,1,1`
4. 修正参数确认后固化进固件默认值（`pushSwapXY/pushSignX/pushSignY`），出厂即正确。

> 注意：判向不依赖世界方位（无磁力计，yaw 不可观测），"前"永远是盒体箭头方向——
> 把盒子在桌面上转 90° 后，沿箭头推仍是 FORWARD。这是特性而非缺陷。
